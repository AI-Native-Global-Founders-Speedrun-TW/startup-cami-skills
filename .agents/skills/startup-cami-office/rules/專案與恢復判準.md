# Rule 1 - 明示專案與唯一正式來源
- Level: `MUST`
- root 優先使用明示路徑，其次從 cwd 向上找最近的 startup-cami.yaml（共用正式資料），或改名前建立、尚未遷移的 startup101.yaml；尚無正式資料以 cwd 為候選。顯示選定路徑，不因為有 Git 就改用 mono 根。多個候選才詢問；不掃 sibling、家目錄或整顆磁碟。
- startup-cami.yaml（共用正式資料）同時保存目前答案、已接受版本、訪談筆記、評估、歷史與 session；HTML 是唯讀衍生物。不能從 localStorage 反灌或用 HTML 的勾選宣告通過。
- 相對路徑解析後不得越過專案 root；遵守目標專案自己的指示。三 skills 共用同版 bundle，不把 CEO 路徑寫入使用者專案。
## Good Example
```text
在指定 startup 資料夾 inspect，找到既有 YAML 後續跑；HTML 只展示其回答。
```
## Bad Example
```text
找到上層 mono Git root，就把另一個 startup 的正式答案覆寫在那裡。
```
# Rule 2 - 訪談筆記、評估與提交必須同版
- Level: `MUST`
- 以繁體中文或英文整理本輪筆記。每個案例寫清楚角色、工作情境、具體行為與結果；保留數字、單位、範圍、時序、因果、取捨、前提、相互衝突的意見及不確定語氣。分清親見、客戶轉述、構想和預期。刪除贅詞、重複、已修正的口誤與明示要剪掉的內容。可拆段或列點，篇幅依資訊量決定；不得將數個案例壓成一句共同痛點。
- 在對話中檢查來訊與筆記的語意覆蓋：每一個案例的角色與數字還在嗎？哪個結果是已發生、哪個只是預期？讀者能從筆記重建爭議、因果、限制與下一步嗎？改寫應能單獨閱讀。保留精確專有名詞，不將整理過的文字放入引號冒充逐字引文。中文一律繁體，包括來自簡體中文來訊的內容。
- 只把整理稿交給 CLI。禁止保存或回顯原始逐字來訊，包括臨時原稿檔、草稿、events、評估、receipt、log、HTML。刪除範圍有疑義時先釐清，不把可能要刪的內容落檔。
- 同一次來訊重試沿用穩定識別。CLI 識別限 1–100 個英文字母、數字、底線或連字號；必要時以對話識別與來訊識別計算 SHA-256，不以訪談正文產生識別。衝突先查既有筆記，不另建識別來繞過衝突。
- 取得 note 重讀結果後才用筆記識別建立單題 draft。候選與筆記分開：將筆記改寫、合併或翻譯成正式答案，仍須展示候選請使用者確認後再評估。勘誤、撤回、不同輪的相同內容，都保留正確的先後與適用對象。
- 使用檔案參數傳入整理稿，不把外部文字插入 shell command。
- accept 必須使用當前 packet hash、評估與 runtime 要求的版本／檔案 hash；被修改的 candidate 要重評。人工修改 answer 不會修改既有 accepted snapshot，也不能讓新文字沿用舊 pass；人工改 key points 不算新評分。
## Good Example
```text
訪談筆記：三位受訪者表示願意試用；未提供付費紀錄。
正式候選：三位受訪者有試用意願。
evidence：reported；不改成三位付費客戶。
```
## Bad Example
```text
將「願意試」改成「強烈付費需求」，沿用修改前的 pass。
```
# Rule 3 - 恢復與交付不得誤報
- Level: `MUST`
- 存檔錯誤、鎖衝突與 unknown commit state 均依 runtime 回報處理；unknown 先 recover，不重送 accept。
- 答案與 receipt 在同一份 YAML 的同一次原子替換中提交。不能以 HTML 生成失敗推斷 YAML 未保存；不確定寫入是否完成時，先重讀並核對提交識別與檔案 hash，不能重複提交。
- 使用者可 skip/defer/stop。保留 draft 並回報未完成，不能降低通過門檻。以 session-action 保存 skip/defer/resume 與原因；停止時保留當前 draft。
- startup-cami.yaml（共用正式資料）包含可攜的完整領域資料；`.startup-cami/`（本地設定；改名前的專案為 `.startup101/`）只承載安裝、路徑與操作設定，不能成為另一份答案或評估來源。模板缺失不阻斷引導及正式記錄。不得自動升級 pinned catalog/rubric。
## Good Example
```text
YAML 已提交；模板未安裝，因此 HTML 尚未更新。可補模板後重跑 render。
```
## Bad Example
```text
HTML 沒產生，所以宣稱全部沒存，重新追加同一答案。
```
